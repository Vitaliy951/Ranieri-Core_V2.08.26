# Архитектура ИИ-скоринга и системы AVM холдинга «Ranieri Core»

## 1. Общая концепция

Платформа «Ranieri Core» предоставляет B2B-клиентам (банкам, МФО, застройщикам) высокоточную оценку кредитных рисков и стоимости залоговой недвижимости на основе сквозного каскадного андеррайтинга. Система использует комбинацию:

- **Регуляторных фильтров** (Hard-Stops по требованиям ЦБ РФ).
- **Моделей градиентного бустинга** (LightGBM/CatBoost) для оценки вероятности дефолта заемщика (PD).
- **Нейросетевой архитектуры LSTR** (Long Short-Term Transformer) для прогнозной оценки стоимости недвижимости на основе 10-летнего Big Data архива.

Все вычисления выполняются в рамках **SLA <= 90 секунд** на один запрос, что обеспечивает сквозную обработку (STP — Straight-Through Processing).

## 3. Детальное описание контуров

### 3.1. Контур А: Регуляторные Hard-Stops

Эти проверки выполняются на основе **нормативных актов Банка России** (Положение № 483-П, № 730-П, макропруденциальные лимиты). Фильтры являются **детерминированными** и не используют машинное обучение.

- **ПДН (Показатель долговой нагрузки):** Рассчитывается как отношение суммы всех ежемесячных обязательств заемщика (включая запрашиваемый ипотечный платеж) к его официальному доходу. Если ПДН > 50% – автоматический отказ.
- **LTV (Loan-to-Value):** Отношение запрашиваемой суммы кредита к стоимости залога (оценивается по данным застройщика или по кадастровой стоимости). Если LTV > 80% – отказ (требуется первоначальный взнос не менее 20%).
- **Наличие критических долгов:** Проверка через API ФССП на наличие открытых исполнительных производств на сумму > 50 000 руб.
- **Статус работодателя:** Проверка через ФНС на предмет банкротства, ликвидации или налоговых задолженностей компании-работодателя.

### 3.2. Контур Б: Оценка вероятности дефолта (ML-Engine)

**Используемая модель:** LightGBM / CatBoost (градиентный бустинг над табличными данными).

**Входные признаки (Feature Engineering):**

- **Данные из СФР** (после авторизации через ЕСИА):
  - Официальный доход за последние 12 месяцев.
  - Стабильность дохода (коэффициент вариации).
  - Длительность трудового стажа у текущего работодателя.
  - Количество работодателей за последние 3 года.
- **Данные из БКИ (кредитная история):**
  - Количество открытых кредитов.
  - Утилизация кредитных карт (отношение использованного лимита к общему).
  - Просрочки (максимальная длительность, количество случаев).
  - Количество запросов в БКИ за последние 30 дней (признак «паники» или фрода).
- **Данные из ФНС и ФССП:**
  - Наличие налоговых задолженностей.
  - Сумма исполнительных производств.
- **Социально-демографические признаки:** возраст, регион, семейное положение (получаются из цифрового профиля).

**Выход модели:**
- Скоринг-балл (от 300 до 850).
- Вероятность дефолта (PD) на горизонте 12 месяцев, калиброванная через логистическую регрессию.

**Критерии принятия решений:**
- Если PD ≤ 0.025 (2.5%) → кредит направляется в **Старший транш (Класс А)** для НПФ.
- Если 0.025 < PD ≤ 0.05 (5%) → кредит направляется в **Мезонинный транш (Класс Б)** для квалифицированных инвесторов.
- Если PD > 0.05 → отказ (REJECT_RISK).

### 3.3. Контур В: Прогнозная оценка залога (AVM SOTA-Engine)

**Используемая модель:** LSTR (Long Short-Term Transformer) – гибридная архитектура на основе механизмов внимания (Multi-Head Attention) и рекуррентных блоков, адаптированная для анализа длинных временных рядов.

**Входные данные:**
- **Технические характеристики объекта:** площадь, тип дома (монолит, кирпич, панель), этаж, год постройки, количество комнат.
- **Географические координаты:** точные GPS-координаты, расстояние до метро, инфраструктурный индекс (количество школ, детских садов, ТЦ в радиусе 1 км).
- **Временной ряд (10 лет):** помесячная динамика цен на аналогичные объекты в радиусе 500 м, извлеченная из ClickHouse (источник: `rebpm`-парсинг 20+ площадок).
- **Макроэкономические факторы:** ключевая ставка ЦБ на момент оценки, региональный индекс инфляции, индекс стоимости строительства (Infoline).

**Выход модели:**
- **Fair Value (справедливая цена):** расчетная рыночная стоимость объекта на текущий момент.
- **Прогнозная стресс-стоимость (Stress Value) через 3 года:** рассчитывается с учетом циклических трендов и заложенного стресс-сценария (падение рынка на 15%).
- **Stress LTV:** отношение запрашиваемого кредита к прогнозной стресс-стоимости.
- **Антифрод-статус:** процент отклонения заявленной застройщиком цены от Fair Value.

**Критерии принятия решений:**
- Если отклонение цены застройщика от Fair Value > 10% → `REJECT_COLLATERAL_OVERVALUED` (искусственное завышение).
- Если Stress LTV > 0.85 → `REJECT_STRESS_LTV_TOO_HIGH` (риск деградации залога при макро-шоке).
- В остальных случаях залог признается приемлемым (`APPROVE_COLLATERAL`).

## 4. Интеграция с источниками данных

### 4.1. Внешние API и адаптеры

- **SMEV_Connector** – модуль для асинхронного обогащения данных через СМЭВ 3.0 (Госуслуги, СФР, ФНС, ФССП). Реализован в `src/aggregators/smev_adapter.py`.
- **Kontur_Adapter** – обертка для коммерческого API Контур.Фокус (быстрый старт до получения прямого доступа к СМЭВ). Реализован в `src/aggregators/kontur_adapter.py`.
- **ClickHouse Client** – подключение к БД аналитики для извлечения 10-летних временных рядов.

### 4.2. Обработка данных в ClickHouse

Таблицы:
- `real_estate_big_data` – архив объявлений с 20+ площадок (история цен, технические характеристики, координаты).
- `macro_indices` – макроэкономические индикаторы (ключевая ставка, инфляция) по месяцам.

Схема таблицы `real_estate_big_data` (упрощённо):

```sql
CREATE TABLE real_estate_big_data (
    ad_id UInt64,
    city LowCardinality(String),
    district LowCardinality(String),
    latitude Float64,
    longitude Float64,
    house_type LowCardinality(String),  -- MONOLITH, BRICK, PANEL
    build_year UInt16,
    total_area Float32,
    rooms_count UInt8,
    floor UInt8,
    max_floor UInt8,
    price UInt64,
    price_per_meter UInt32,
    parse_date Date,
    first_seen_date Date,
    last_seen_date Date,
    is_active UInt8,
    -- макро-контекст на дату парсинга
    cb_key_rate Float32,
    regional_inflation Float32
) ENGINE = ReplacingMergeTree(parse_date)
PRIMARY KEY (city, district, house_type)
ORDER BY (city, district, house_type, parse_date);

5. MLOps-цикл: мониторинг и переобучение
5.1. Метрики мониторинга

    Data Drift (PSI): Еженедельный анализ распределения входных признаков. Alert при PSI > 0.25 по любой из топ-5 значимых фичей.

    Concept Drift (MAPE): Ежемесячная проверка ошибки прогноза AVM (MAPE). Alert при MAPE > 6% (целевой порог ≤ 4.5%).

    Бизнес-метрики (Gini): Ежеквартальный бэк-тестинг модели кредитного скоринга. Alert при Gini < 0.60 (целевой порог ≥ 0.65).

5.2. Автоматический пайплайн переобучения (Airflow DAG)

    Сбор свежих данных за последние 3 месяца из ClickHouse.

    Обучение модели LSTR на расширенном историческом датасете (10 лет + новые данные).

    Валидация на отложенной выборке (MAPE, коэффициент детерминации R²).

    Сравнение с текущей production-моделью.

    Если новая модель лучше (MAPE ≤ 4.5%) – деплой новой версии в MLflow и обновление контейнера.
