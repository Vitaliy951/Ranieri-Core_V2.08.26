Что делает этот пайплайн:

    Тестирование (run_tests)

        Устанавливает зависимости из requirements.txt.

        Запускает flake8 для проверки стиля кода.

        Запускает pytest с покрытием, сохраняет отчёт о покрытии.

        Выполняется при пушах в main, develop и в Merge Request'ах.

    Сборка Docker-образа (build_secure_image)

        Собирает образ на основе Dockerfile.

        Пушит его в Yandex Container Registry с тегами (SHA коммита и latest).

        Запускается только при пушах в main.

    Сканирование безопасности (container_security_scan)

        Использует Trivy для поиска уязвимостей.

        Критические уязвимости (CRITICAL) останавливают пайплайн.

        Высокие (HIGH) только логируются.

        Запускается только для main.

    Деплой в Production (deploy_to_production)

        Обновляет образ в Kubernetes Deployment ranieri-api в namespace ranieri-prod.

        Ждёт успешного развёртывания (rollout status).

        Запускается вручную (when: manual) для контроля.

        Привязан к окружению production.

    Деплой в Staging (deploy_to_staging)

        Аналогично, но для develop ветки.

        Запускается автоматически после сборки (без ручного подтверждения).

🛠️ Требуемые переменные окружения (CI/CD)

Добавьте их в настройках GitLab (Settings → CI/CD → Variables):
Переменная	Описание
YANDEX_CLOUD_OAUTH_TOKEN	OAuth-токен для доступа к Yandex Container Registry
K8S_PROD_SERVER	URL API-сервера Production Kubernetes
K8S_PROD_TOKEN	Токен для аутентификации в Production Kubernetes
K8S_STAGING_SERVER	URL API-сервера Staging Kubernetes
K8S_STAGING_TOKEN	Токен для аутентификации в Staging Kubernetes
📁 Рекомендации по настройке

    Убедитесь, что в корне проекта есть Dockerfile и requirements.txt.

    В Kubernetes-кластере должны быть созданы namespaces ranieri-prod и ranieri-staging, а также Deployment с именем ranieri-api (и ranieri-api-staging для staging).

    Для работы kubectl на GitLab Runner'ах используйте теги docker и k8s – их нужно назначить раннерам.

Этот конвейер полностью готов к использованию и соответствует лучшим практикам CI/CD, обеспечивая безопасность, автоматизацию и контроль релизов.🚀
